# Example: BerthPlan

A filled-in reference showing what the kit produces for a **fictional** project. BerthPlan, its code, issue keys and links are invented; nothing here describes a real product or company.

BerthPlan is a berth-scheduling portal for a mid-sized port: harbour planners book vessel calls into berth windows, and the backend warns about conflicts.

| File                                                                                                     | Shows                                                                                                             |
| -------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------- |
| [AGENTS.md](AGENTS.md)                                                                                   | A complete instruction file for a Java/Spring Boot backend and Angular frontend, using the generic add-on profile |
| [CLAUDE.md](CLAUDE.md)                                                                                   | The Claude Code pointer                                                                                           |
| [docs/setup.md](docs/setup.md)                                                                           | Repository-specific first-time setup                                                                              |
| [docs/plans/BP-142-berth-window-conflict-warning.md](docs/plans/BP-142-berth-window-conflict-warning.md) | A story plan after hand-off, with ticked steps, a deviation and the acceptance-criteria evidence table            |

Use it to calibrate the level of detail, not as content to copy. Links to BerthPlan's own READMEs, ADRs and source files are part of the fiction and do not resolve; the plan template it uses is the kit's [skeletons/docs/plans/\_template.md](../../skeletons/docs/plans/_template.md).
